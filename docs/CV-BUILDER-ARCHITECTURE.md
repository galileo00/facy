# خطة معمارية: منصة عمل سيفيهات (CV Builder) — ريبو واحد، موقعين

## السياق

المطلوب: ويب أبلكيشن بيعمل سيفيهات (CVs)، والمنظومة كلها موقعين:

1. **موقع ووردبرس** — صفحة تعريفية (Landing) ومدونة بس، مفيش ربط تقني بالأبلكيشن.
2. **الأبلكيشن نفسه** — Next.js / React، هو اللي فيه الفورم والمعاينة الحية وتصدير الـ PDF.

القرارات الأساسية:

- التقنية: **Next.js / React**.
- الووردبرس دوره landing + blog بس، وفيه زرار بيودّي على الأبلكيشن.
- التوصية للاستضافة: ووردبرس على استضافة مشتركة + الأبلكيشن على Vercel.

---

## 1. فكرة "ريبو واحد لموقعين" (Monorepo)

الريبو **مش بيستضيف** المواقع — الريبو فيه *الكود بتاعك انت بس*، وكل جزء بيتنشر لمكانه:

```
cv-builder/                        ← الريبو الواحد
├── apps/
│   └── web/                       ← أبلكيشن الـ CV (Next.js)
│       ├── package.json
│       ├── src/...
│       └── ...
├── wordpress/
│   └── themes/
│       └── cv-landing/            ← الثيم المخصوص بتاع موقع الووردبرس
│           ├── style.css
│           ├── functions.php
│           └── ...
├── .github/
│   └── workflows/
│       ├── deploy-app.yml         ← (اختياري) لو مش هتستخدم ربط Vercel المباشر
│       └── deploy-wp-theme.yml    ← بيرفع الثيم للاستضافة بـ FTP/SFTP
└── README.md
```

**قاعدة ذهبية:** ووردبرس نفسه (الـ core والـ plugins الجاهزة) **ما يتحطش في الريبو**. اللي يتحط بس هو الثيم/البلجن اللي انت كاتبه. ووردبرس بيتسطّب مرة واحدة على الاستضافة وبيتحدّث من لوحة تحكمه.

## 2. الدومينات وتوزيع المواقع

| الموقع | الدومين | المحتوى |
|---|---|---|
| ووردبرس | `example.com` | Landing page + مدونة + زرار "اعمل سيفيك دلوقتي" |
| الأبلكيشن | `app.example.com` (سب دومين) | الـ CV builder نفسه |

الربط بينهم مجرد **لينكات** (الزرار في الووردبرس بيفتح `app.example.com`) — مفيش API ولا تسجيل دخول مشترك.

## 3. الاستضافة والنشر (التوصية)

- **الووردبرس:** استضافة مشتركة عادية (Hostinger / Namecheap / أي cPanel) — رخيصة ومناسبة تمامًا لـ landing + مدونة.
- **الأبلكيشن:** **Vercel** (مجاني للمشاريع الشخصية):
  - بتربط حساب Vercel بالريبو على GitHub، وتحدد `Root Directory = apps/web`.
  - كل `git push` على `main` = deploy تلقائي. وكل PR بياخد Preview URL لوحده.
  - السب دومين: سجل `CNAME` من `app.example.com` → `cname.vercel-dns.com` في DNS بتاع الدومين.
- **نشر ثيم الووردبرس:** GitHub Action (زي `SamKirkland/FTP-Deploy-Action`) بيرفع فولدر `wordpress/themes/cv-landing` للاستضافة عند أي تعديل فيه — أو رفع يدوي بـ zip في البداية.

النتيجة: ريبو واحد، و**كل push بينشر كل جزء لمكانه أوتوماتيك**.

## 4. الأبلكيشن نفسه — مكونات الـ CV Builder

- **Stack:** Next.js (App Router) + React + Tailwind CSS.
- **الفورم:** أقسام (بيانات شخصية، الخبرات، التعليم، المهارات، اللغات، كورسات) — إدارة الحالة بـ React state/Zustand.
- **معاينة حية:** الـ CV بيتحدث لايف جنب الفورم أثناء الكتابة.
- **قوالب (Templates):** كل قالب مجرد component بياخد نفس الـ data — يبدأ بقالبين تلاتة.
- **تصدير PDF:** الطريقة الأبسط والأدق = CSS للطباعة + `window.print()` (بيطلع PDF نضيف بمقاس A4). بديل: `@react-pdf/renderer`.
- **الحفظ:** المرحلة الأولى `localStorage` (من غير حسابات ولا داتابيز خالص → الأبلكيشن كله static تقريبًا ورخيص جدًا في الاستضافة). لو حبيت حسابات بعدين: Supabase/Firebase.
- **اللغة:** دعم عربي RTL + إنجليزي من البداية (مهم جدًا لسيفيهات عربي).

## 5. مراحل التنفيذ

1. **هيكل الريبو:** إنشاء `apps/web` (scaffold Next.js) + `wordpress/themes/cv-landing` — يُفضَّل ريبو جديد نضيف للمشروع ده بدل الحشر جوه ريبو الأندرويد الحالي.
2. **MVP للأبلكيشن:** فورم البيانات + معاينة حية + قالب واحد + تصدير PDF + حفظ في localStorage.
3. **قوالب إضافية + عربي/إنجليزي (RTL).**
4. **ثيم الووردبرس:** landing بسيطة + زرار للأبلكيشن (أو حتى ثيم جاهز + Elementor لو مش عايز كود).
5. **الربط والنشر:** Vercel + DNS + (اختياري) Action لنشر الثيم.
